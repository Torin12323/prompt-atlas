## 使用与验证

```sh
npm ci
npm run check:library
npm run build
npm run dev
```

`scripts/check-library.mjs` 检查分类、双语字段、ID/文本/配图重复、参考链接、版本信息和文件完整性。
更新记录见 [CHANGELOG.md](CHANGELOG.md)；版本统计和来源见 `public/data/library-release.json`、`prompt-sources.json` 和 `image-sources.json`。

已完成数据与图片完整性检查，以及搜索/筛选/排序、复制、收藏、双语、明暗模式、表单失败保留草稿、账号数据隔离与CSRF检查；浏览器复核公共浏览和详情页面。生成效果未逐条实测。

## 现有功能

- 搜索、筛选、收藏和一键复制
- 中英文切换、亮色和深色模式；Baleday品牌字体和系统UI文字

## 托管

当前部署在 OpenAI Sites，Cloudflare D1 使用 `DB` 绑定。现有数据库结构与迁移在 `db/`、`drizzle/`。
登录和退出由 Sites 平台处理，身份由平台可信请求头提供。本地预览保持匿名，不模拟真实账号。
迁移到其他平台时必须替换身份验证实现，不能信任公网请求自行提供的身份头。

`PROMPT_ATLAS_OWNER_EMAIL` 是平台服务端秘密配置，用于原有个人记录的兼容读取，不包含在仓库中。
GitHub同步不会自动完成其他托管平台部署。
